Your vault, on your terms.

One real SQLite file

Your original images, PDFs, descriptions, and favorites are stored together inside a .sqlite database. Description search uses SQLite full-text search. File contents are not OCR-scanned or indexed.

Keep it next to this page

Choose Save database and save paperVault.sqlite beside index.html. Reopen the page and choose Open database to continue. Your browser requires your permission to access that file.

Save your changes

Edits stay in memory until you save. Supported browsers let you pick a file and update it on later saves. Other browsers download a new copy; reopen your latest copy next time. Closing without saving loses your changes.

Private does not mean encrypted

This app makes no network requests. The database and downloaded documents are unencrypted, and anyone with access to them can read them. Use device encryption and protect your backups. This is a prototype for personal use.

Prototype limits

JPEG, PNG, WebP, GIF, and PDF uploads. Up to 15 MB per file and 100 MB per database. Open only trusted paperVault databases. Search matches description words and their prefixes, with all search words required.
